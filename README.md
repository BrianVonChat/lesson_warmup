# Music Theory Flashcards - Warm-up Game

An interactive music theory warm-up game for piano students with difficulty scaling from 1-20.

## Features

- **Difficulty Levels**: 1-20 scale that adjusts question complexity
- **Multiple Question Types**:
  - Note identification (treble and bass clef)
  - Interval recognition
  - Chord identification
  - Key signature recognition
  - Scale degree identification
- **MIDI Support**: Use your MIDI keyboard to answer questions
- **Timed Rounds**: 3-minute rounds designed for average students
- **Real-time Feedback**: Instant scoring and progress tracking
- **Music Notation**: Professional music notation rendering using VexFlow

## Getting Started

1. Open `index.html` in a modern web browser (Chrome, Edge, or Opera recommended for MIDI support)
2. Connect your MIDI keyboard (optional but recommended)
3. Select a difficulty level (1-20)
4. Click "Start Round" to begin
5. Answer questions using:
   - Computer keyboard for multiple choice
   - MIDI keyboard for note/chord playing

## Difficulty Scale

- **1-5**: Beginner - Basic note reading, simple intervals
- **6-10**: Elementary - Extended range, major/minor triads, common key signatures
- **11-15**: Intermediate - Complex intervals, seventh chords, all key signatures
- **16-20**: Advanced - Enharmonic notes, extended chords, modal scales

## Browser Compatibility

- MIDI support requires Chrome, Edge, or Opera
- Firefox and Safari: Keyboard input only

## Technologies

- HTML5, CSS3, JavaScript (ES6+)
- Web MIDI API
- VexFlow for music notation rendering
